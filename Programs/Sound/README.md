# SID-Ulator Sound

A collection of BASIC programs demonstrating musical notes and sound effects
on the RC2014 SID-Ulator sound module, including lasers, sirens, gunshots,
explosions and an engine.

## Hardware

The programs require:

- An RC2014 Mini II running Microsoft BASIC with the `OUT` statement
- An RC2014 SID-Ulator sound module configured for **D4/D5** (hexadecimal)
- Headphones or powered speakers connected to the module's audio jack
- A serial terminal for loading programs and displaying messages

The program selects a SID register through port **212** (D4) and writes
its value through port **213** (D5).

## Program Files

| File          | Description                                                                  |
| ------------- | ---------------------------------------------------------------------------- |
| scale.bas     | Plays an ascending C-major scale from C4 to C5 using a triangle tone         |
| laser.bas     | Fires five laser shots with rapidly falling sawtooth tones                   |
| siren.bas     | Plays five continuous rising-and-falling triangle-tone siren cycles          |
| gunshot.bas   | Plays five sharp noise bursts with fading tails                              |
| explosion.bas | Plays five blasts combining a bright noise impact and a longer coarse rumble |
| engine.bas    | Idles, revs up and slows down three times using pulse and noise voices       |

## Running the Program

Load the required program into BASIC and enter `RUN`.

If you interrupt a program and a note keeps sounding, enter `OUT 212,24 : OUT 213,0` at the BASIC prompt to mute the card.

## Sound Settings

### Scale settings

- Change `DL = 500` on line 20 to adjust note length
- Larger values play more slowly; loop timing depends on the RC2014's CPU speed.
- Change the final value on line 110 (`10`) to set volume from 0 to 15.

### Laser settings

- On line 20, `NS = 5` sets the number of shots and `DL = 5` controls the delay at each pitch step. Increase `DL` for a slower sweep
- Line 180 sweeps the frequency word from 24000 down to 1000 in steps of 1000 (roughly 1431 Hz down to 60 Hz with nominal 1 MHz tuning)
- Smaller steps give a smoother, longer sweep
- If changing the starting value, also change `F = 24000` on line 140
- Line 240 controls the pause between shots
- Change the final value on line 100 (`10`) to set volume from 0 to 15

### Siren settings

- On line 20, `NC = 5` sets the number of rise-and-fall cycles and `DL = 20` controls the delay at each pitch step. Increase `DL` for a slower siren
- On line 30, `FL = 6000` and `FH = 18000` set the low and high frequency words (roughly 358 Hz and 1073 Hz with nominal 1 MHz tuning)
- Keep these between 1 and 65535, with `FH` greater than `FL`
- `FS = 300` on line 30 sets the pitch step
- Use a positive whole number that divides `FH - FL` exactly so both sweeps meet at the endpoints
- Smaller steps make the sweep smoother and longer
- Change the final value on line 110 (`10`) to set volume from 0 to 15

### Gunshot settings

- On line 20, `NE = 5` sets the number of shots. `DL = 5000` leaves time for the release tail before the next blast
- Increase it if the next blast or the final mute cuts the tail short
- On line 30, `VL = 10` sets master volume; use a whole number from 0 to 15. `RL = 10` sets the envelope release rate: larger values give longer tails, up to 15
- Increase `DL` as needed when increasing `RL`
- The release is generated by the SID, independently of BASIC
- Line 140 sets the fixed noise frequency word (`6000`). Keep it between 1 and 65535. This controls the noise texture, not a musical note
- Lower frequency words give a coarser noise texture; higher values give a brighter hiss
- There is no frequency sweep during the blast
- Line 190 controls how long the initial blast holds before release

### Explosion settings

- On line 20, `NE = 5` sets the number of blasts
- `DL = 8000` leaves time for the fading tail; increase it if the next blast or final mute cuts the tail short
- On line 30, `VL = 10` sets master volume (0-15) and `RL = 11` sets the rumble release rate (0-15)
- Higher release values give longer tails and may need a larger `DL`
- Line 190 sets the impact noise frequency word (`16000`); line 210 sets the rumble noise frequency word (`1500`)
- Both remain fixed
- These control noise texture, not musical pitch
- Keep them between 1 and 65535; lower values give coarser noise
- Line 250 controls the brief hold before both voices start fading

### Engine settings

- On line 20, `NC = 3` sets the number of rev cycles and `DL = 20` sets the delay at each pitch step
- Increase `DL` for slower revving
- On line 30, `FL = 800` and `FH = 4800` set the idle and maximum frequency words (roughly 48 Hz and 286 Hz at nominal 1 MHz tuning)
- These are sound frequencies, not calibrated engine RPM
- `FS = 100` sets the step size
- Use positive whole numbers with `FL < FH`, choose `FS` to divide `FH - FL` exactly, and keep `FH` at or below 21845 because the noise frequency word is three times the pulse frequency word
- `VL = 10` on line 30 sets master volume (0-15)
- Lines 210 and 350 set the idle holds; line 280 sets the high-rev hold
- The final value `4` on line 100 sets a 25 percent pulse duty cycle
- Try `8` for a 50 percent square wave and a different engine timbre

## Implementation Notes

### Scale

The scale program clears registers 0 through 24, sets voice 1's envelope and master volume, then reads eight frequency words from `DATA`. Each word is split into low and high bytes for registers 0 and 1. Register 4's value 17 selects a triangle wave and starts the note; 16 releases it.

The frequency words use the SID's nominal 1 MHz tuning convention:

```text
word = frequency * 16777216 / 1000000
```

The value is rounded to the nearest integer. Absolute pitch may vary with the emulator's tuning. The delay loops control note duration, not pitch.

### Laser

The laser program uses the same initialisation and frequency-byte split. Register 4's value 33 starts a sawtooth tone; successive frequency writes lower its pitch while the gate stays on. Value 32 releases the tone at the end of each sweep.

### Siren

The siren keeps voice 1's triangle waveform gated on while sweeping the frequency up and down, so there is no break between cycles. It releases the gate only after the final cycle and then mutes the card.

### Gunshot

The gunshot selects the noise waveform with register 4's value 129. It holds the noise frequency and master volume steady, then releases the gate with value 128 after a short burst. Voice 1's envelope produces the fading tail. Register 6 combines full sustain (240) with the selected release rate. BASIC waits for the tail before retriggering or muting.

### Explosion

The explosion extends the gunshot's envelope approach to two voices. Voice 1 supplies bright noise with sustain level 8 and release rate 7; voice 2 supplies coarse noise with sustain level 15 and release rate 11 by default. Both select noise with control value 129 and release with 128 after a short hold. Their envelopes fade independently while master volume stays fixed. The bright crack dies away first, leaving the coarse rumble. Neither voice uses a pitched waveform or a frequency sweep. The explosion uses two of the SID's three voices.

### Engine

The engine uses voice 1's pulse waveform (control value 65) and voice 2's noise waveform (129). Pulse width is set to 1024 out of 4096, giving a 25 percent duty cycle. Both voices stay gated on throughout the revs. The frequency subroutine updates the pulse and noise together; the noise uses a lower sustain level so the engine buzz remains prominent. At the end, both voices are released and the card is muted.
