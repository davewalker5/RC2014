# Cavern Stalker

<img src="https://github.com/davewalker5/RC2014/blob/main/Programs/CavernStalker/cavernstalker.png" alt="Cavern Stalker" width="600">

_Cavern Stalker_ is a text adventure for RC2014 BASIC.

## Hardware

The program requires:

- An RC2014 computer running BASIC
- A serial terminal

No extra hardware is needed.

## Program Files

| File              | Description                                 |
| ----------------- | ------------------------------------------- |
| cavernstalker.bas | Implementation of the 'Cavern Stalker' game |

## Running the Program

Load `cavernstalker.bas` into BASIC and enter `RUN`.

## Playing the Game

A dangerous creature is loose in a twenty-chamber cavern, alongside hidden abysses and troublesome Gloomwings. Read the environmental clues, choose your route carefully and stop the creature before your five launcher bolts are gone.

Each chamber has three exits. At every turn you may:

- **Walk** into an adjoining chamber
- **Fire** a bolt along a route of one, two or three connected chambers
- **Leave** the game

Nearby dangers produce clues, but their exact locations remain hidden. _Gloomwings_ may carry the player elsewhere, while entering an abyss or the creature's chamber ends the search. A missed attack can also cause the creature to move.

## Acknowledgements

The design owes its central inspiration to Gregory Yob's 1973 game *Hunt the Wumpus*, which introduced the landmark idea of hunting a hidden adversary in a numbered cave network. Cavern Stalker is an original implementation for the RC2014 with independently written code, rules text, messages and documentation; it does not reproduce the original program's wording or source.
